# Manage Intervention

작업 중 지적은 원래 작업을 버리는 사유가 아니다. 지적을 고친 뒤 멈춘 행으로 돌아가는 것이 이 Skill의 목적이다.

## 1. 진입

- `manage_decision decide`가 프롬프트를 `개선`(다른 프로젝트 작업에도 이어지는 작업 과정·Skill·절차·hook·작업 도구 결함 지적·개선 요구)으로 판정하면 개입 상태다. 사례로 든 제품이 아니라 작업관리기 루트(`/home/tree/extensions`, Table7 1198)가 소유자다.
- `질문`으로 판정된 이유·의견 질문은 개입이 아니다. 답부터 한다.
- 단, 메인 자신의 과정 행위를 따지는 질문("왜 니가 직접 고쳤냐", "왜 위임/개선자 호출을 안 했냐", "왜 아무것도 안 했냐")은 순수 질문이 아니라 개입이다. 이유를 한두 문장으로 답한 뒤 같은 턴에 2절 기록과 3절 수정·개선자 호출로 바로 들어간다. 사용자가 개선자를 다시 요구할 때까지 기다리지 않는다.
- 진행 중인 백그라운드 위임·검증 태스크(`manage_task kill`·`tmux kill-pane`)를 멈추고, 끝난 태스크에 `dispatch-agent --attach`를 다시 걸지 않는다.

## 2. 기록

- 중단한 원래 행마다 `$D`에 `[⏸] 개입 #<개입 행> <지적 한 줄>`을 쓴다(`grist task-update <id> --project <dir> --fields '{"D": "…"}'`). `$H`는 바꾸지 않는다. 개입용 `$H` 값은 없다.
- 지적은 작업관리기 새 행으로 기록한다(`grist request-record` → `task-add`, `manage-project` `stage-start.md`). 이미 `확인`·`완료`된 행의 증거로 대신하지 않는다(`task-complete`가 거부).

## 3. 수정

- 규칙·Skill 문구와 기존 hook·`~/ai/scripts` 작업 도구의 작은 결함(10줄 미만 패치)은 메인이 직접 고친다. 새 함수 파일이나 30줄 이상 추가하는 작업 도구 기능은 `dispatch-agent --agent codex`로 맡긴다. 사용자가 위임을 지시했으면 규모와 관계없이 위임한다.
- 문구보다 절차 수정을 먼저, 차단 규칙은 그 뒤에 고른다(`manage-global-rules` §1).
- 같은 행에서 2회 이상 실패했거나 착각이 있었으면 개선자를 부른다(`manage_improve` §2, 작업 규칙은 `role-improver`).
- 제품 파일 탐색·제품 행 재개는 하지 않는다(`main-edit-gate`가 거부). 오분류로 시작한 제품 작업, 사용자가 "차후에/나중에"로 뺀 작업은 원복·취소하고 다시 시작하지 않는다.

## 4. 확인

- 고칠 규칙·Skill·hook·도구를 먼저 모두 바꾼 뒤 확인은 마지막에 한 번만 한다. 변경 하나마다 빌드·hook 실행·Grist 기록을 반복하지 않는다.
- 고친 hook·명령을 hook과 같은 최소 환경(`env -i HOME=… PATH=/usr/bin:/bin`)에서 차단 사례와 허용 사례로 한 번씩 실행해 출력으로 확인한다.
- 과정 게이트가 제품 행의 마감·재개를 막는 동안에는 `test/tmp/`의 독립 입력과 임시 표식으로 같은 hook·바이너리의 차단·허용을 확인하고, 개입 행의 근거로 기록한다. 제품 행의 실제 런타임 검증은 5절 복귀 뒤 수행한다. 제품 행 검증을 개입 행 마감의 선행 조건으로 삼지 않는다.
- 개입 행은 일반 행처럼 `task-confirm`·`manage_improve`·`task-complete --row`로 마감한다. 확인 전에는 완료를 보고하지 않는다.

## 5. 복귀

- 개입 행이 `확인`되면 2절에서 `[⏸]`를 붙인 원래 행으로 돌아가 그 행의 단계 카드(`manage-project` 하위 진입 표)를 이어 간다.
- 복귀하면 `$D`의 `[⏸]` 줄을 그 행의 최신 진행 한 줄로 덮어쓴다. 사용자가 원래 작업을 보류하라고 했으면 `[🏷] 사용자 대기 — <사유>`로 남긴다.
- 최종 보고에는 `개입: #<개입 행> → 복귀 #<원래 행>` 또는 `보류 #<원래 행>` 한 줄을 넣는다.
