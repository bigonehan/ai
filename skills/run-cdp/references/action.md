# 사용자 행동 (drag·연속 마우스 제스처)

- Drag는 Stagehand가 연속된 브라우저 수준 마우스 제스처를 보낼 때만 Stagehand로, 아니면 같은 탭에 순차 브라우저 수준 CDP 마우스 입력으로 보낸다. `page.evaluate`·합성 DOM 이벤트·핸들러 직접 호출로 대신하지 않는다.
- For a requested drag gesture, move the browser pointer to the visible starting object, press, move through the intended range while held, and release at the visible endpoint. Capture and open the visible browser screen once while the mouse is held and again after release. In both images, check the rendered selection range, which expected objects are included or missed, and whether text or images are selected unintentionally. If either drag screenshot is unavailable or obscured, fail the interaction check until the screen can be inspected. A `dragAndDrop` return value, successful `Input.dispatchMouseEvent` replies, DOM checkbox counts, `window.getSelection()` values, or a passing unit test alone never establishes that the drag worked. If the screen disagrees with those values, end with the `실패 — <행>` line for the drag.
